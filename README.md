# Employee Analytics Dashboard | Power BI

## Project Overview
An interactive employee analytics dashboard built using Microsoft Power BI to explore workforce distribution, hiring trends, salary metrics, and remote work patterns.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization

## Key Insights
- DevOps has the highest employee count, with 189 employees.
- Remote and non-remote employees are almost equally distributed.
- Hiring peaked in 2023, with 228 joiners.

## Dashboard Features
- Total Employees and Average Salary KPIs
- Department-wise employee distribution
- Yearly hiring trend (2020–2024)
- Remote work distribution
- Department and Region slicers for interactive filtering
